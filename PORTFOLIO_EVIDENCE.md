## Evidence standard

Each repository should expose:
1. a runnable domain or delivery proof;
2. machine-readable CI artifacts;
3. reproducible test/coverage evidence where applicable;
4. an architecture-to-evidence mapping;
5. a README path from the project claim to the underlying proof.

The goal is to make engineering claims reviewable from source and CI output rather than relying on screenshots or prose alone.
